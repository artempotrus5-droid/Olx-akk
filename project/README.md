# OLX Accounts Bot

Внутренний Telegram-бот для распределения корпоративных OLX-аккаунтов между сотрудниками.

## Возможности

- ➕ Добавить аккаунт (пошагово: email → пароль → год и описание)
- 📋 Взять аккаунт (список свободных/занятых, атомарная выдача)
- 🔄 Вернуть аккаунт (только свои)
- 🗑 Удалить аккаунт (с подтверждением)
- 📖 История аккаунтов — общая для всех, открывается как Telegram Mini App

Хранилище — SQLite, создаётся автоматически при первом запуске.

## Быстрый запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env   # заполните BOT_TOKEN
export $(cat .env | xargs)
python main.py
```

Бот и HTTP-сервер (health-check + Mini App) запускаются одной командой в одном процессе.

## Деплой на Render

1. Создайте бота через **@BotFather** в Telegram, получите `BOT_TOKEN`.
2. Загрузите этот проект в GitHub-репозиторий.
3. На [render.com](https://render.com) создайте **New → Web Service**, подключите репозиторий (Render автоматически найдёт `render.yaml` и `Dockerfile`).
4. В настройках сервиса укажите переменную окружения `BOT_TOKEN` (значение токена).
5. Запустите деплой. После первого успешного деплоя скопируйте выданный Render URL (например `https://olx-accounts-bot.onrender.com`) и добавьте его как переменную окружения `WEBAPP_URL`, затем передеплойте — кнопка «📖 История аккаунтов» откроется как Mini App.
6. Проверить работоспособность: `https://<ваш-домен>/health` → `{"status":"ok"}`.

> На бесплатном тарифе Render диск не подключается — при передеплое база SQLite может обнулиться. Для сохранности данных подключите платный план с постоянным диском (в `render.yaml` уже описан раздел `disk`) или используйте план, который его поддерживает.

## Переменные окружения

| Переменная    | Обязательна | Описание                                          |
|---------------|:-----------:|----------------------------------------------------|
| `BOT_TOKEN`   | да          | Токен бота от BotFather                            |
| `WEBAPP_URL`  | нет         | https-адрес сервиса, для кнопки истории (Mini App) |
| `PORT`        | нет         | Порт HTTP-сервера (Render подставляет сам)         |
| `DB_PATH`     | нет         | Путь к файлу SQLite (по умолчанию `data/accounts.db`) |

```
│   └── static/index.html — страница истории (Telegram Mini App)

├── requirements.txt
├── Dockerfile
├── render.yaml
└── .env.example
```
